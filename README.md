# AnomalyDash

AnomalyDash is a web-based online examination platform designed to help colleges conduct online exams while identifying unusual examination behaviour for faculty review.

## Project Status

🚧 Under development.

## Repository Structure

- `frontend/` — Student and faculty web interface
- `backend/` — Server-side application and APIs

## Team

Hackathon project by the AnomalyDash team.
